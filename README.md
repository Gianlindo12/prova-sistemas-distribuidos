Problema da empresa: executar un calculo para outro programa.

-servidor.py: recebe a chamada RPC e executa o calculo
-cliente.py: solicita o calculo ao servidor e mostra a resposta

Preço final: 180.0

respostas:

1- o calculo foi executado no servidor.py, pois é o servidor que recebe a chamada RPC e realiza a ação.

2- o programa que iniciou foi o cliente .py

3- o cliente nao conseguiria obter o resultado, pois nao haveria servidor disponivel para receber e executar as chamadas RPC.
